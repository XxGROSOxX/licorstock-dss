# Acuerdos de Trabajo del Squad

## Daily Scrum
El equipo realizará reuniones breves de seguimiento por WhatsApp.

## Flujo de Git
- La rama main será usada para versiones estables.
- La rama develop será usada para integrar avances.
- Cada funcionalidad se trabajará en una rama feature.
- Toda integración se realizará mediante Pull Request.

## Nomenclatura
- Variables y funciones en camelCase.
- Tablas de base de datos en snake_case.
- Ramas con formato feature/nombre-funcionalidad.
- Commits claros y descriptivos.
